# Text-to-Emoji Converter 😃

A simple, lightweight Python project that takes regular sentences as input and automatically replaces classic keyboard emoticons with their modern emoji equivalents. 

I built this project as a fun way to practice and learn the basics of Python, string manipulation, and dictionaries.

## ✨ Features
* Parses input strings and identifies standard keyboard emoticons.
* Converts a variety of common text faces (like `:)`, `:(`, `<3`) into Unicode emojis.
* Simple, easy-to-read code structure perfect for beginners.

## 🚀 Example
**Input:**
`I am Sad :(`

**Output:**
`I am Sad ☹️`

## 🛠️ Built With
* **Python 3.14.6** - Standard library only (No external dependencies required).
